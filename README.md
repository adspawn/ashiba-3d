# 足場設計 3D

くさび式足場（Aタイプ）をブラウザ上で3D配置し、使用部材の数量と総重量を自動集計する設計ツールです。
インストール不要。`index.html` をブラウザで開くだけで動きます（Three.js を CDN から読み込むため、インターネット接続が必要です）。

## 機能

- 部材：支柱・踏板・手摺・ジャッキベース・階段（品番・単重は国産くさび式足場Aタイプの規格値）
- スナップ ON/OFF（`S` キー）
  - ON：支柱はジャッキベースや下の支柱に差し込み、手摺・踏板・階段は支柱のコマ（450mm間隔）に接続
  - OFF：作業高さの平面上に自由配置（`R` キーで15°回転）
- 拾い出し表：品番ごとの数量・重量、総数量・総重量、未接続部材の数、外形寸法
- 表をコピー（Excelに貼り付け可）
- 一括作成：スパン数・スパン長・建地幅・段数を指定して自動で組み立て
- 元に戻す／やり直し、JSONでのデータ入出力、ブラウザへの自動保存

## 操作

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ / 右ドラッグ / ホイール | 回転 / 平行移動 / ズーム |
| クリック | 配置・選択 |
| `1`〜`5` | 支柱・踏板・手摺・ジャッキベース・階段 |
| `V` / `X` | 選択 / 削除ツール |
| `Delete` | 選択中の部材を削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `F` | 全体表示 |
