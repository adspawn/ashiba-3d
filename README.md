# 足場設計 3D

くさび式足場（Aタイプ）をブラウザ上で3D配置し、使用部材の数量と総重量を自動集計する設計ツールです。
インストール不要。`index.html` をブラウザで開くだけで動きます（Three.js を CDN から読み込むため、インターネット接続が必要です）。

## 機能

- 部材：支柱・踏板・手摺・ジャッキベース・階段（品番・単重は国産くさび式足場Aタイプの規格値）
- 支柱（KSA）：本体の下端から240に最初のコマ、以降450ピッチ、最後のコマから上端まで210。上端に125のほぞ、下端から70にピン穴（KSA-09＝240＋450＋210＝900）
- 筋交い（KSL-18 / 12 / 09）：スパン×高さ＝1800×1800 / 1200×1350 / 900×900 の対角をコマからコマへ渡す。上り・下りはマウスに近い方
- 単管パイプ φ48.6（0.5〜5m・500刻み）：支柱・手摺・筋交い・単管にクランプ位置で取り付け。`R` で水平／垂直
- 直交クランプ・自在クランプ：部材の交差部に吸着。斜めの交差に直交クランプを使うと警告
- フラット鋼板（安全鋼板）幅500×2m／3m：水平の手摺・単管に取り付け。`R` で縦置き／横置き／屋根置き（寝かせる）
- ※単管・クランプ・鋼板の重量と単価は目安（単価は「単価を編集」で変更可）
- 人（身長170cm）：寸法確認用。踏板・階段・地面の上に立たせ、`R` で向きを回転。集計には含めない
- 合板 1820×910×12：横置き・縦置きを `R` で切替（選択中の合板も回転可）。横置きは上の手摺と450下、縦置きは上の手摺と1350（無ければ900・450）下の手摺につば付きフック4本で掛ける。フック数は「合板の枚数×4」で自動計上（合板・フックの重量は目安）
- スナップ ON/OFF（`S` キー）
  - ON：支柱はジャッキベースや下の支柱に差し込み、手摺は支柱のコマ（450mm間隔）に接続。踏板は向かい合う手摺と手摺の間に、階段は下の手摺と1800上・1800先の手摺に掛ける（空いている区画に吸着）
  - OFF：作業高さの平面上に自由配置（`R` キーで15°回転）
- 拾い出し表：品番ごとの数量・重量・金額、総数量・総重量、未接続部材の数、外形寸法
- 価格計算：合計金額（税抜・税込）。初期単価は足場JAPAN 国産くさび式足場Aタイプの掲載価格（税抜）、合板1,500円・つば付きフック150円。「単価を編集」で品番ごとの単価と消費税率を変更可（ブラウザに保存、JSONにも含む）
- 表をコピー（Excelに貼り付け可）
- 一括作成：スパン数・スパン長・建地幅・段数を指定して自動で組み立て
- 元に戻す／やり直し、JSONでのデータ入出力、ブラウザへの自動保存

## 操作

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ / 右ドラッグ / ホイール | 回転 / 平行移動 / ズーム |
| クリック | 配置・選択 |
| `1`〜`9`・`0`・`-` | 支柱・踏板・手摺・ジャッキベース・階段・合板・筋交い・人・単管・クランプ・鋼板 |
| `V` / `X` | 選択 / 削除ツール |
| `Delete` | 選択中の部材を削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `F` | 全体表示 |
